# Mercado San Martín · Frontend

Sitio web informativo del Mercado San Martín (Huaycán, Ate).

## Tecnologías

- [Vite](https://vitejs.dev/)
- Vanilla JavaScript & CSS moderno
- GSAP, Lenis, Leaflet, PhotoSwipe

## Desarrollo

```bash
npm install
npm run dev
```

## Producción

```bash
npm run build
npm run preview
```
